# Pet Shelter: routing (Task 5)

React + React Router. Routes: `/`, `/about`, `/pets`, `/pets/:id`, `/dashboard`, `/login`, `*` (404).

    npm install
    npm run dev       # development
    npm run deploy    # builds and publishes to the lab-05 folder of the gh-pages branch

Uses HashRouter (`/#/pets/3`) so refresh and direct links work on GitHub Pages.
